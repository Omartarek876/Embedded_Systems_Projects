# Embedded Systems Projects

A collection of Omar Tarek's embedded systems and related engineering projects. The projects cover low-level microcontroller drivers, digital hardware applications, embedded Linux, AUTOSAR, robotics, sensing, and a clinic management system.

Each project is stored in its own directory. The files are copied from the `main` branch of the corresponding source repository so the projects can be browsed together in one place.

## About this collection

This repository provides a single overview of the projects while retaining each project's own files and README in its folder. These are file snapshots of the source repositories' `main` branches; the original repositories remain the canonical source for their commit history and future updates.
